# Hello World C++

Projet minimal en C++ affichant `Hello, World!`.

## Prérequis

Un compilateur C++ installé sur votre machine.

## Compilation

```bash
g++ main.cpp -o hello
```

## Exécution

Windows :

```bash
hello.exe
```

Linux/macOS :

```bash
./hello
```

## Résultat

```text
Hello, World!
```
